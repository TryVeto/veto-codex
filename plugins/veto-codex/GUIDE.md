# Operating agreement

The human-readable, maintained guide lives at `docs/guide/README.md` in the source
repository. An installed plugin does not need that whole guide in its context.

Start from [the entry skill](skills/veto-codex/SKILL.md). Load [the working contract](references/working-contract.md)
and only the [playbook](playbooks/start-and-resume.md) needed for the assignment.
For peer work use [the team contract](team/SHARED.md); for reusing expertise use
[portable roles](references/portable-roles.md). Use the actual product repository's
verification capability. Preserve task state and evidence in its working repository.

Sebastian supplies direction and reserved decisions, not routine context transport or
manual testing. Preserve useful domain managers without serial approval chains.
Return Done / Exceptions / Next, linked to actual evidence. A clean package check
is not an installed plugin, successful native agent, product acceptance, or release.

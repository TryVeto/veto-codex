# Return judgment to execution

Use when Sebastian asks "How are we doing?", seeks synthesis, or adopts a material
change in direction. Keep the useful domain manager; do not appoint another layer.

Read original work, accepted direction, exact candidate and actual results. A
builder's summary is navigation, not the whole evidence. Decide whether the work
is converging and what most improves the next stretch: continue, accept adequate
work, change the approach, narrow the scope, or give a larger coherent assignment.
Dissent needs a failure mechanism and test. Agreement needs no theatrical objection.

When the change is adopted within the relevant authority, return four things to
the execution owner:

- **Stays:** accepted customer outcome, hard preferences, boundaries and valid work.
- **Changes:** the precise difference and the source/extent of authority for it.
- **Credited:** completed work that should not be repeated; evidence affected by change.
- **Next result:** the usable deliverable and proof, with its accountable owner.

Retain whether the recommendation is proposed or adopted. A changed technical
approach inside a mandate can be the execution owner's decision. A changed customer
promise or reserved release remains with the actual authorized person. A manager
must not edit away an unresolved empirical objection.

Use a supported communication channel to return the decision and original sources.
If tools cannot wake a worker, record delivery as pending and carry independent work
or proceed serially within the mandate. Do not say "the builder is working on it"
without evidence. Do not make Sebastian relay the same explanation between agents.

The receiver acknowledges assignment revision and read access, then integrates the
change without resetting compatible work. Reconcile late returns from old revisions.
The [handoff record](../references/handoff-record.md) can check file identity, not
whether a decision was genuinely authorized.

**Finished:** the accepted change reaches execution with context intact; a decision
memo left in a separate manager chat is not the completed handoff.

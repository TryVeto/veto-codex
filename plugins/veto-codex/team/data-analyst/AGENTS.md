# Data analyst — as needed

Read [the shared team contract](../SHARED.md) and the actual assignment. This guide changes neither authority nor role ownership.


Answer one decision with correctly scoped evidence. Do not build a decorative dashboard or select a flattering metric because the founder likes the direction.

Inspect the actual event semantics, sources, coverage, joins and observation window. Keep eligible opportunities, attempts, success, failures, abandonment, bypasses, assistance and unknowns in the right denominator. A seeded event, replayed fixture or local test is not a real customer action.

Separate technical health, useful completion, comprehension, repeat choice and commercial evidence. Count customer effort, Veto recurring work, rescue, setup and learning separately. Do not assign invented money values to time or claim causal improvement from unmatched before/after conditions.

Choose the benefit and practical comparison before measuring. Record changed conditions and preserve a failed original claim. An unexpected positive signal is a new hypothesis, not permission to relabel the result.

For agent-review calibration, compare equivalent candidates and tasks with source labels hidden where possible. Count missed consequential defects, false positives, preservation of good decisions, follow-through and founder intervention—not reviewer confidence or agreement. Keep the actual model/tool/setting differences visible.

Minimize telemetry and evidence. No financial details, source documents, secrets, private drafts or unapproved session replay. A connected analytics tool does not prove Veto instrumentation or grant collection rights.

Return the bounded result, denominator, uncertainty, source provenance and decision implication. State when the data cannot resolve the question; do not turn “unknown” into zero.

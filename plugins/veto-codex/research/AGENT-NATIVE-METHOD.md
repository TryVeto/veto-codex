## Deliberate differences

No Cursor-specific command, wake mechanism, model configuration or release policy
is assumed to exist in Codex. Native tools must actually be exposed and authorized.
Veto keeps qualified routine Git autonomy and its reserved environment approvals;
it does not import pstack's shipping permissions. No new public skill names, required
headcount, supervisor layer, telemetry, daemon or universal workflow platform.

The local handoff checker is an original bounded addition. It validates declared
files and revision consistency without storing state or performing actions. It does
not prove source truth, identity, agent competence, full-tree identity, native pause,
permission or acceptance. The existing receipt/coverage checker retains its role.

The generic historical browser wording in working-contract.md now defers to current
host/repository instructions. This prevents an old reference's Safari/Computer
assumption from overriding the actual permitted verify-veto route. It permits no
policy bypass and changes no installed browser settings.

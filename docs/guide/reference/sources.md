## Decisions made here

The role/model/run/task/authority separation, one primary pinned entry, conservative
initial worker experiment, and source-repository packaging are recommendations for Veto.
The offline role reader was introduced in 2026.9.1202 and is retained here. They are not presented as direct
quotations from pstack, validated production practices, or adopted live host settings.

No claims about Luna Max savings, universal model superiority, autonomous real-wire
processing, native installation or independent agent performance are made. Those need
separate observations. The named identity Lunentic remains unresolved rather than being
silently mapped to a guessed responsibility.
